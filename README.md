# VitrinePro AI

Plataforma de vitrines digitais, produtos, serviços e experiências com foco em inteligência artificial.

## Stack
- Next.js 15 + React 19 + TypeScript
- Interface responsiva premium em azul-marinho e dourado
- Ícones Lucide e interações de navegação, busca e filtros
- Preparada para integração futura com Supabase, pagamentos e serviços de IA

## Executar localmente
```bash
npm install
npm run dev
```
Abra http://localhost:3000.

## Publicar na Vercel
Importe este repositório em https://vercel.com/new. A Vercel detecta Next.js automaticamente. Esta prévia visual não exige variáveis de ambiente.

## Estado do projeto
Esta primeira entrega é uma prévia navegável de interface. Cadastro real, persistência de dados, checkout, agendamentos, IA conectada e painel administrativo ainda precisam ser implementados e configurados antes de produção.
